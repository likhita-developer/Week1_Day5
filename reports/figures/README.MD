# Employee Data Analysis Project

## Project Overview
This project focuses on employee data cleaning, exploratory data analysis and data visualisation using Python.

## Dataset
The dataset contains 100 employee records with information about:
- Employee ID
- Name
- Age
- Gender
- Department
- City
- Experience
- Salary
- Joining Date
- Performance Rating

## Project Tasks
1. Data cleaning using Pandas.
2. Exploratory data analysis.
3. GroupBy and correlation analysis.
4. Data merging and pivot tables.
5. Creating five visualisations using Matplotlib.

## Visualisations
The project includes:
1. Employee count by department.
2. Employee age distribution.
3. Experience vs salary scatter plot.
4. Salary trend by joining date.
5. Employee salary distribution box plot.

Install the required packages using:

## How to Run
1. Open the project folder in VS Code.
2. Activate the virtual environment.
3. Install the required packages.
4. Run the Python scripts.
5. Open the Jupyter notebook to view the analysis and charts.
